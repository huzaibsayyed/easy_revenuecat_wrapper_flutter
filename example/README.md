# easy_revenuecat_wrapper_flutter example

A minimal Flutter app demonstrating `easy_revenuecat_wrapper_flutter`:
initializing `RevenueCatService`, reading subscription status reactively,
and showing the paywall via `RevenueCatSubscriptionButton`.

## Running

1. Replace `_revenueCatApiKey`, `_entitlementId`, and `_offeringId` in
   [lib/main.dart](lib/main.dart) with the values from your own RevenueCat
   dashboard.
2. Run the app:

   ```sh
   flutter run
   ```
